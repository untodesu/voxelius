# Development: requirements

## For compiling

1. A C++20 compiler;  
2. A C99 compiler;  
3. CMake and a working backend for it;  
4. Python 3.x for scripts;  

## For actual development

1. A text editor, maybe even an IDE;  
2. Knowing how to write in C++20 and not make code that looks like C++98 with templates sprinkled on top of it;
